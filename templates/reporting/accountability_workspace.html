What a profile controls
Employees edit familiar labels, source offices, exact approved reports or tax forms, required/optional flags, and plain-language instructions. GRAND pins the reviewed version and does not expose SQL or executable templates.

How to assemble an accountability package

  1. A configuration preparer writes the local checklist as a package profile; a different approver activates it.
  2. An Accounting preparer chooses the profile and exact reporting period.
  3. For each slot, choose only the approved GRAND evidence offered by the system.
  4. Submit to pin source UUIDs, status, periods, and SHA-256 checksums.
  5. A different reviewer approves or returns the package with a correction note.
  6. Export the approved manifest into the department/user/category folder that TraceSync can copy without extra setup.

For a user mistake before approval, replace the selection and record why. After approval, create a linked successor; never edit or delete the approved record.
