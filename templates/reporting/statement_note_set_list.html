How to prepare statement notes

  1. Select control-reconciled position and performance runs for the same exact period.
  2. Complete each candidate topic using retained schedules and reviewed authority. Mark a topic not applicable only with a reason.
  3. Link disclosures to the pinned statement lines where useful.
  4. Submit to freeze the note text, source runs, mappings, and checksums.
  5. A different Accounting reviewer may accept controlled working notes. Official approval remains blocked until both statements and the local note package are formally accepted.
