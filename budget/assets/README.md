# Office-form print font

Noto Sans Regular is embedded in office-form PDFs for Filipino names, peso signs
and ordinary Latin punctuation. Its SIL Open Font License is retained in `OFL.txt`.
Unsupported characters fail issuance explicitly instead of becoming missing-glyph boxes.
